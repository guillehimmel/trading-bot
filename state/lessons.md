# Lecciones aprendidas (revisadas y aprobadas)

Este archivo es la única fuente de "aprendizaje" del CEO entre backtests: no se
edita automáticamente. Después de cada backtest, `backtest/run_backtest.py`
genera una propuesta en `backtest/results/<timestamp>_lecciones_propuestas.md`
usando el agente "analista". Un humano la revisa y, si está de acuerdo, copia
(o reescribe) las lecciones que valen la pena acá abajo, debajo del encabezado.

Mientras el marcador `<!-- sin lecciones aprobadas todavía -->` esté presente
(o el archivo esté vacío), el CEO no recibe ningún campo de lecciones — borralo
cuando agregues la primera lección real.
